# TechZone - Loja de Tecnologia

Projeto de site fictício TechZone com três páginas: Página principal, Produtos e Contato.

## Estrutura do site
- `index.html` - Página principal
- `produtos.html` - Página de produtos
- `contato.html` - Página de contato
- `styles.css` - Estilos globais do site

## Como usar
1. Abra `index.html` no navegador.
2. Navegue entre as páginas usando o menu.

## Observações
- Para versão final, crie commits separados quando cada página for adicionada.
- Faça o deploy do projeto no Vercel e adicione o link do site aqui.
- Adicione também o link do repositório no GitHub.
